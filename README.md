# 오늘의 밈언 — 카카오 챗봇 스킬 서버

기분/상황을 말하면 존잼 · 진지 · 황당 · 썰렁 · 철학 다섯 가지 텐션 중 하나를 골라
**사진 위에 자막이 합성된** 밈+명언 카드를 보여주는 카카오톡 챗봇의 **스킬 서버**입니다.
에코 튜토리얼(https://developers.kakao.com/docs/in/bot/tutorial) 다음 단계인
"진짜 답변을 생성하는 서버"에 해당합니다.

## 대화 흐름

1. 사용자가 오늘 기분/상황을 자유 텍스트로 입력 (예: "오늘 회사에서 스트레스 많이 받았어")
2. 봇이 컨셉 선택 버튼 5개를 제시: 😆 존잼 · 🧐 진지 · 🤯 황당 · 🥶 썰렁 · 🏛️ 철학
3. 하나를 고르면 그 컨셉의 밈언 카드(이미지+텍스트)를 응답
4. 카드 아래 후속 버튼 제공
   - 🔁 비슷한 밈언 더 — 같은 컨셉에서 다른 항목 (중복 없이 순환, 다 보면 자동 리셋)
   - 🔀 다른 컨셉 — 컨셉 선택 화면으로 복귀 (기분/상황은 기억한 채로)
   - 🆕 다른 기분/상황 — 세션 초기화 후 처음부터

세션은 카카오가 주는 `userRequest.user.id` (botUserKey) 기준으로 서버 메모리에 저장합니다.
서버를 여러 대로 스케일 아웃할 계획이면 `lib/session.js`를 Redis 등으로 바꿔주세요.

## 이미지는 어떻게 만들어지나요 (핵심)

카카오 basicCard는 이미지와 텍스트가 분리되어 있어서, "사진 위에 자막이 박제된" 느낌을 내려면
직접 이미지를 합성해서 내려줘야 합니다. `lib/compose.js`가 컨셉/항목마다 아래 우선순위로
배경을 정하고, `lib/cardImage.js`(canvas)로 실제 합성을 합니다.

1. **`item.localImage`가 있고 `public/memes/`에 실제 파일이 있으면** → 이미 자막이 박혀있는
   이미지로 보고 리사이즈만 해서 그대로 사용 (`renderRawPhoto`). 저작권이 있는 캡처짤 등
   본인이 사용 권한을 가진 이미지를 직접 넣고 싶을 때를 위한 확장 포인트이며, 기본 상태에는
   어떤 파일도 들어있지 않습니다.
2. **`item.person`이 있으면(진지/철학)** → 위키피디아 REST 요약 API로 그 인물의 실제 사진을
   실시간으로 가져와서(`lib/wiki.js`), 그 위에 명언 자막을 새로 그려 합성합니다(`renderPhotoCard`).
3. **`item.stockQuery`가 있으면(존잼/황당/썰렁 등)** → [Openverse](https://openverse.org)
   무료 CC 라이선스 스톡 이미지 검색 API(`lib/stock.js`, API 키 불필요)에서 그 검색어와
   어울리는 사진을 실시간으로 받아와 자막을 합성합니다. `license_type=commercial`로 걸어서
   비교적 자유롭게 재사용 가능한 라이선스만 가져오고, CC 라이선스의 저작자 표시(attribution)
   요건을 지키기 위해 카드 하단 출처 텍스트에 사진작가 이름을 자동으로 함께 적어줍니다
   (예: `- 국룰 짤방 명언 · 사진: Jane Doe (Openverse)`).
   2번/3번 모두 컨셉별로 자막 스타일이 다릅니다 (`data/content.js`의 `captionStyle`):
   - `burst` (존잼/황당): 예능 자막처럼 삐죽삐죽한 흰색 말풍선 + 굵은 검정 글씨
   - `bar` (진지/썰렁): 사진 하단 그라데이션 바 + 굵은 흰 글씨
   - `plain` (철학): 사진 위에 바로 외곽선 있는 글씨만 (소크라테스 사진 예시 스타일)
   조회가 실패하면(네트워크 문제, 결과 없음 등) 자동으로 4번 fallback으로 내려갑니다.
4. **그 외(사진이 아예 없을 때)** → 자체 제작 컬러 카드 (`renderQuoteCard`, fallback)

> 무한도전 같은 실제 방송 캡처짤은 방송사 저작권이 있는 콘텐츠라 이 저장소에 기본으로
> 포함하거나 자동으로 긁어오지 않았습니다. 대신 Openverse 스톡 이미지로 "사진+자막" 형태를
> 저작권 걱정 없이 구현했고, `localImage` 확장 포인트도 열어뒀으니 나중에 본인이 사용 권한을
> 가진 이미지가 생기면 그걸 최우선으로 쓰도록 바꿀 수 있습니다.

이미지 합성은 채팅 응답 시점이 아니라 **카카오가 실제로 이미지 URL을 요청하는 시점**
(`GET /api/card/:concept/:id.png`)에 이루어집니다. 스킬 응답 자체는 URL 문자열만 즉시
돌려주기 때문에, 카카오의 스킬 타임아웃(5초) 안에 항상 안전하게 끝납니다. 한 번 합성한
이미지는 메모리에 캐시해서 재사용합니다.

### 이미지 출처 요약

각 항목은 `person`(실존 인물)과 `stockQuery`(스톡 이미지 검색어)를 동시에 가질 수 있고,
`lib/compose.js`가 아래 순서로 시도해서 처음 성공하는 걸 씁니다.

| 우선순위 | 소스 | 적용 대상 | 비고 |
|---|---|---|---|
| 1 | `public/memes/`에 직접 넣은 이미지 | 아무 항목이나(`localImage`) | 본인이 사용 권한을 가진 이미지 전용 확장 포인트, 기본은 비어있음 |
| 2 | 위키피디아 인물 사진 (실시간 조회) | 진지/철학 전체 + 존잼 일부(`person` 지정된 항목) | 무료, 라이선스 확인됨 |
| 3 | Openverse CC 스톡 이미지 (실시간 검색) | `stockQuery`가 있는 모든 항목 (2번 실패 시 fallback 포함) | 무료, API 키 불필요, 작가명 자동 표기 |
| 4 | 자체 제작 컬러 카드 | 그 외 전부 | 위 3개가 다 실패했을 때의 최종 fallback |

**존잼 컨셉에 실존 인물 어록을 추가했습니다** — 말씀하신 대로 무한도전 박명수 어록처럼 온라인에
잘 알려진 "명언"들을 실제 인물 사진과 함께 보여주는 게 이 컨셉의 핵심이라, `jj1`(박명수 "늦었다고
생각할 때가...")과 `jj7`(박명수 "티끌 모아 티끌"), `jj8`(무하마드 알리), `jj9`(마이클 조던)에
`person` 필드를 넣어 위키피디아 사진을 자동으로 붙였습니다. 이 4개는 `stockQuery`도 같이
넣어뒀기 때문에, 혹시 위키에서 그 인물 사진을 못 찾으면 자동으로 비슷한 느낌의 스톡 사진으로
대체됩니다. 나머지 항목(`jj2`~`jj6`)은 특정 인물이 아니라 밈/속설 성격이라 계속 Openverse
스톡 사진을 씁니다.

실존 인물의 정확한 발언 여부가 불확실하거나 논쟁의 소지가 있는 어록은 오귀속 위험 때문에
일부러 넣지 않았습니다 — 새 인물을 추가하실 때도 출처가 확실한 문구 위주로 넣으시는 걸
권장합니다.

방송 캡처짤처럼 저작권이 걸린 이미지는 이 프로젝트가 대신 구해다 쓰지 않습니다. 필요하면
1번 방법(`localImage`)으로 직접 넣을 수 있게 코드는 이미 열어뒀습니다.

## 로컬에서 실행하기

```bash
npm install
cp .env.example .env   # 필요하면 값 수정
npm start              # http://localhost:3000
```

`POST /skill` 이 카카오가 호출할 웹훅입니다. 아래처럼 로컬 테스트도 가능합니다:

```bash
curl -X POST http://localhost:3000/skill \
  -H "Content-Type: application/json" \
  -d '{"userRequest":{"utterance":"오늘 좀 힘들었어","user":{"id":"test-user"}}}'
```

응답의 `thumbnail.imageUrl`을 브라우저에 열어보면 실제 합성된 이미지를 바로 확인할 수 있습니다.

## 카카오 i 오픈빌더에 연결하기

이 서버는 인터넷에서 접근 가능한 URL이 있어야 카카오 서버가 호출할 수 있습니다.

1. **공개 URL 만들기** (택 1)
   - 개발 중 빠른 테스트: `ngrok http 3000` 실행 후 나오는 `https://xxxx.ngrok-free.app` 주소 사용
   - 실제 제출/배포: Render, Railway, Fly.io, 또는 사내 인프라에 배포 (Node 18+, `npm start`)
2. 챗봇 관리자센터(오픈빌더) → **스킬** 메뉴 → 새 스킬 서버 추가
   - URL: `https://<공개주소>/skill`
   - (권장) 헤더 설정에서 `.env`의 `KAKAO_SKILL_HEADER` / `KAKAO_SKILL_SECRET` 값과 동일한
     이름/값의 커스텀 헤더를 추가하면, 누군가 이 웹훅 주소를 알아내도 함부로 호출할 수 없습니다.
3. **블록** 설정 → 사용자의 기분/상황을 받을 블록(또는 폴백 블록)에서
   답변 방식을 "스킬"로 바꾸고, 방금 등록한 스킬 서버를 연결
4. 저장 후 **봇 테스트**로 대화해보고, 문제 없으면 **배포**
5. (선택) 콜백을 쓰고 싶다면(응답이 5초를 넘길 것 같을 때) `AI 챗봇 관리`에서 콜백을 신청하고,
   응답에 `useCallback: true`를 포함해 `userRequest.callbackUrl`로 별도 POST — 이 서버는
   이미지 합성을 응답 이후로 미뤄뒀기 때문에 보통 콜백 없이도 충분합니다.

메뉴 이름/위치는 오픈빌더 버전에 따라 조금씩 다를 수 있어요. 이미 에코까지 만들어보셨다면
"스킬 서버 URL 등록 → 블록에 스킬 연결"이라는 큰 흐름은 동일합니다.

## 콘텐츠 추가/수정하기

`data/content.js`를 열어 각 컨셉 배열에 항목을 추가하면 됩니다.

```js
// 사진 없이 자체 제작 카드로
{ id: 'jj7', quote: '새 밈언 문구', source: '출처/설명' }

// Openverse 스톡 이미지 검색어로 자동 합성 (영어 키워드일수록 검색 결과가 잘 나옵니다)
{ id: 'jj8', quote: '...', source: '...', stockQuery: 'coffee morning desk' }

// 실존 인물 (위키피디아 사진 + 자막 자동 합성)
{ id: 'jj9', quote: '...', source: '아무개', person: { ko: '한국어 위키 제목', en: 'English wiki title' } }

// (선택) 본인이 사용 권한을 가진 이미지를 직접 넣고 싶을 때
{ id: 'jj10', quote: '...', source: '...', localImage: 'jj10.jpg' }
```

## 폴더 구조

```
server.js            # 익스프레스 앱 + /skill 웹훅 + /api/card 이미지 라우트
data/content.js       # 밈언 콘텐츠 데이터베이스 (+ 컨셉별 자막 스타일)
lib/kakao.js          # 카카오 SkillResponse JSON 빌더
lib/session.js        # 사용자별 대화 상태(메모리)
lib/wiki.js           # 위키피디아 초상 이미지 조회 (캐싱 포함)
lib/stock.js          # Openverse 무료 CC 스톡 이미지 검색 (캐싱 포함)
lib/cardImage.js      # canvas로 카드 이미지 그리기 (합성/원본리사이즈/자체제작)
lib/compose.js        # concept+item -> 최종 PNG 오케스트레이션 (우선순위 로직)
assets/fonts/         # Pretendard 폰트 (OFL 라이선스, 한글 렌더링용)
public/memes/         # 직접 준비한 이미지(자막 있는 캡처짤 등)를 넣는 곳
```

## 라이선스 / 크레딧

- 폰트: [Pretendard](https://github.com/orioncactus/pretendard) — SIL Open Font License 1.1
- 진지/철학 인물 이미지: Wikipedia REST Summary API (요청 시점에 실시간 조회, 각 이미지의 라이선스는
  해당 위키백과 문서/커먼즈 페이지를 따릅니다)
- 존잼/황당/썰렁 배경 이미지: [Openverse](https://openverse.org) (CC 라이선스 이미지 검색, 카드
  하단에 작가명을 자동 표기하여 저작자 표시 요건을 지킵니다)
- `public/memes/`에 직접 추가하는 이미지의 저작권/사용 권한은 사용자 본인 책임입니다.
